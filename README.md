# Student Result Management System

## 📌 Project Description
The Student Result Management System is a simple C programming project that accepts marks for three subjects, validates the marks, calculates total marks and percentage, and displays the student's result and grade.

## 🚀 Features
- Accept marks for three subjects.
- Validate marks between 0 and 100.
- Calculate total marks.
- Calculate percentage.
- Display Pass or Fail status.
- Display grade based on percentage.

## 🛠️ Technologies Used
- C Programming
- GCC Compiler
- Linux Terminal

## 📂 Project Files
- `main.c` — Entry point of the program.
- `Student.c` — Contains the result calculation logic.
- `Student.h` — Contains the function declaration.

## ▶️ How to Compile and Run

Compile the program:

```bash
gcc main.c Student.c -o Myexe
```

Run the program:

```bash
./Myexe
```
